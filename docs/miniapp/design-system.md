# 宝贝时光设计系统

## 设计方向

- 方案：C「苹果小清新」。
- 目标：轻盈、温暖、低压力，适合抱娃时单手快速记录。
- 品牌识别：顶部浅粉色窗口卡片与红、黄、绿三个小圆点。
- 首页标题卡片使用更舒展的高度，并从 50 条本地温暖、乐观且富有诗意的短句中随机展示一条；页面停留期间每 10 分钟随机更换，切到后台时暂停计时，返回后按已过去时间续接。短句不依赖网络，也不涉及医疗或育儿结论。女宝使用浅粉背景，男宝使用浅蓝背景，未填写性别使用浅黄背景，并配低饱和枫叶装饰。
- 平台约束：保持微信胶囊、状态栏避让、底部安全区和不小于 88rpx 的主要触控区域。

## 页面与导航

原生 `tabBar` 使用四项：首页、记录、成长、我的。正式项目提供 8 张本地 PNG，分别对应正常态与选中态；不使用网络图标、SVG、iconfont 或 emoji。

| 页面 | 核心任务 |
| --- | --- |
| 首页 | 查看今日概览、快速新增喂奶/成长记录、查看下次提醒 |
| 记录 | 浏览、筛选、编辑和删除喂奶与成长记录 |
| 成长 | 切换体重、身高、头围，查看周/月/全部趋势 |
| 我的 | 管理宝宝档案、家庭成员、提醒和权限状态 |

## WXML/WXSS 落地映射

| 原型元素 | 小程序实现 | 来源 | 风险或降级 |
| --- | --- | --- | --- |
| 顶部窗口卡片 | `<view>` + WXSS | 原生 | 胶囊位置用 `wx.getMenuButtonBoundingClientRect()` 动态避让 |
| 红黄绿圆点 | 三个 `<view>` | 原生 | 纯装饰，不承担点击语义 |
| 数据卡片与列表 | `<view>` / `scroll-view` | 原生 | 安卓真机检查阴影，必要时仅保留边框 |
| 主要按钮 | `<button>` | 原生 | 提供按下、加载、禁用状态 |
| 分段选择 | `<view>` + `bindtap` | 自研轻组件 | 当前项同时使用背景和文字，避免只依赖颜色 |
| 成长曲线 | Canvas 2D | 微信 Canvas | 数据少于两条时降级为单点与引导文案 |
| 录入抽屉 | 自定义底部弹层 | 原生 WXML/WXSS | 使用安全区；键盘弹出时真机检查 |
| 底部导航 | 原生 `tabBar` | `app.json` | 使用本地 PNG；原型字符图标仅作占位 |
| 订阅提醒 | `wx.requestSubscribeMessage` | 微信平台能力 | 拒绝后显示重新开启路径，不循环强制请求 |

## 交互原则

- 当前时间和当前记录人默认填入；首版新增喂奶默认选择“母乳”，默认时长 15 分钟。
- 至少填写一个成长指标即可保存，异常值提示但不清空输入。
- 删除需要二次确认；首版喂奶记录提供显式删除入口，并清楚提示删除后不可恢复。
- 保存失败保留表单内容；网络恢复后允许重试。
- 提醒设置在云端数据返回前统一显示“—”，不使用业务默认值冒充数据库数据；加载成功后再展示真实值。
- 首页下次喂奶时间由最近一次喂奶时间、数据库提醒间隔和安静时段计算；没有有效记录或未开启时显示明确状态，不显示固定演示数据。
- 首页概览卡片移除“今天过得怎么样”，保留右上角动态“下次提醒”；删除页面底部重复的“轻轻提醒你”提醒条。
- 首页和“我的”宝宝摘要根据生日显示精确到天的年龄，按“岁/月/天”省略零值；未满一岁且整月时显示“4月龄”这类文案。男宝显示“皮夹克”，女宝显示“小棉袄”，未填写性别显示“小宝贝”。
- 仅查看成员隐藏写操作，并说明联系管理员的方式。
- 家庭邀请可生成 24 小时邀请码并转发微信卡片；接收者冷启动后从页面参数恢复邀请码，不依赖发送者本机缓存。
- 颜色始终配合文字和图标，不单独表达风险或状态。
- 所有页面使用纯 WXML/WXSS 的秋风枫叶飘落动效；装饰层不承载信息、忽略触摸并位于内容后方，不影响卡片、文字和图表，也不依赖外部图片。

## 验证状态

- 已验证：HTML 中的信息层级、页面跳转和主要表单流程。
- 待验证：微信开发者工具编译、Canvas 曲线、原生 `tabBar` 图标、安卓与 iPhone 安全区、字体放大和键盘弹出。
- HTML 原型中的阴影和过渡均可由 WXSS 实现；若低端安卓表现不稳定，降级为细边框和无动画，不影响信息层级。

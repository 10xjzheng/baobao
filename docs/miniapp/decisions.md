## 已确认决策

### 决策：首版后台与费用边界

- 选择：微信小程序云开发 CloudBase 免费体验；不启用自动续费、按量付费、短信、AI、付费存储或其他收费能力。
- 原因：家庭成员需要跨设备共享；首版只有少量结构化文本数据，适合快速落地。
- 备选方案：纯本地存储无法家庭共享；后续迁移到自有 HTTPS 服务和数据库。
- 费用或审核风险：免费体验不是永久承诺；到期前必须迁移或停用，控制台实际套餐和额度需用户最终确认。
- 用户确认：只使用免费能力，并要求保留迁移到自有服务器的方案。
- 确认日期：2026-10-04

### 决策：数据访问边界

- 选择：页面只调用统一 repository；首版 repository 可切换本地演示适配器与 CloudBase 云函数。
- 原因：EnvId 尚未验证，同时降低未来迁移到自有服务器的改动范围。
- 备选方案：页面直接调用数据库，迁移和权限审查成本更高。
- 费用或审核风险：本地演示数据不支持真实家庭共享；云端能力只有部署和验证后才可用。
- 用户确认：先快速落地，后续可迁移自有服务器。
- 确认日期：2026-10-04

### 决策：成长记录完整性与删除

- 选择：新增成长记录至少填写体重、身高、头围之一，空缺项沿用最近一次有效值；成长记录支持二次确认后单条删除。
- 原因：减少重复输入，同时保证每条新记录可完整支撑三条成长曲线；误操作可以撤销错误数据。
- 备选方案：允许空值会让曲线出现断点；前端单独补齐无法防止绕过校验，因此补齐和权限校验都在服务端重复执行。
- 费用或审核风险：不增加付费服务；删除为不可恢复操作，保留二次确认，并限制管理员或记录创建者执行。
- 用户确认：用户明确要求成长记录删除和自动补齐空值。
- 确认日期：2026-10-04

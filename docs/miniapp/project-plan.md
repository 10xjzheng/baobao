# 小程序项目规划

## 产品

- 产品名称：宝贝时光
- 目标用户：育儿妈妈、爸爸及被邀请的家庭成员
- 要解决的问题：快速记录宝宝喂奶和成长数据，并让家庭成员共同查看与维护
- 用户最重要的一次操作：在首页两步内完成一条喂奶或成长记录
- 核心业务规则：单宝宝；喂奶支持母乳、奶粉、混合；成长支持体重、身高、头围；家庭角色分管理员、可编辑、仅查看
- 使用者和协作方式：管理员邀请家人；编辑者可新增和修改记录；查看者只读
- 数据保留和共享要求：需要换手机保留，并由家庭成员共享同一批数据
- 外部业务资料来源：
- 高影响字段确认状态：已确认（2026-10-04）
- 需求确认日期：2026-10-04
